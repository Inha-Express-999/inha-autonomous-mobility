# 운송 단계별 재접속 검증 — 2026-11-08

Python 물리 배차 회귀 시험 26건 통과. 기존 Starlette TestClient 경고 1건.

추가한 5개 시나리오는 픽업 이동, 승차 서비스, 목적지 이동, 하차 서비스, 차고 복귀 중 연결을 끊고 10초 경과 후 새 연결을 만드는 과정이다.

공통 확인 항목
- 연결이 끊긴 동안 요청 상태와 운송 단계가 진행되지 않는다.
- 승하차 체류 시간은 초기화된다.
- 이전 연결 토큰의 관측은 거부된다.
- 재연결 첫 응답은 제동 및 목표 속도 0이다.
- 같은 요청과 V01 배정을 유지하고 새 임무를 생성한다.
- 이후 도착 및 체류 관측을 공급하면 운송 완료와 차고 복귀까지 진행한다.
- 최종 요청과 배차 작업은 각각 1건이다.

시험은 합성 도착 좌표와 관측 시간을 공급하는 Python 상태 전이 검증이다. Unity 물리 주행, 실측 재접속 시간, 모바일 화면은 이번 검증 범위에 포함하지 않았다.

재실행은 저장소에서 PYTHONPATH를 backend/src와 필요한 의존성 경로로 설정하고 다음 명령을 사용한다.

python -m pytest backend/tests/test_physical_dispatch.py -q
