# 경로 기반 Greedy/Hungarian 배차 비교

2026-09-26 · v0.4.1.0 체크포인트

## 구현과 재현

실제 서비스의 후보 생성 로직을 `MobilityService.dispatch_candidates()`로 분리했다. 서비스 배차와 비교 도구가 동일한 경로 시간·접근성·차량 용량·우선순위를 사용한다. 비교는 복제된 동일 요청/차량 snapshot에서 실제 `_dispatch_queued_requests()`를 실행하므로 Hungarian batch 크기, 부분 매칭, Greedy fallback과 장기 대기 공정성 처리도 포함한다. 전체 행렬을 무조건 최적화하는 독립 실험과는 범위가 다르다.

```text
campus-sim dispatch-route-compare --scenario configs/dispatch_route_benchmark.json --repetitions 20
```

각 사례는 기존 합성 6-stop graph에 차량 3대를 배치한다. 요청은 API 검증을 거쳐 모두 대기시킨 뒤 비교하며, 재현용 ID만 고정한다. 지도 전체, 차량 능력, 요청 시각/마감, 혼잡·경로·배차 설정과 fairness counter를 결과에 기록하고 fingerprint를 계산한다. 기본·이동지원/마감·장기 대기 화물·요청 후 도로 폐쇄·차량 수 초과 요청의 5개 사례가 있다.

비용은 현재 구현 그대로 `pickup + 0.5*trip + 2*lateness` 초다. 완료 예측에는 pickup/dropoff 서비스 시간도 포함한다. 각 가능한 차량-요청 조합에 pickup/trip node·edge·거리·구간 속도 상한·비용 가산과 시간 성분을 기록한다. 기록된 경로 시간과 실제 배차 비용 cache가 일치하는지도 검사한다. 불가능한 조합에는 `None`과 용량/서비스 필요·경로 없음·가용성 사유를 남긴다.

## 측정 결과

각 방식/사례를 20회 반복했으며 선택 결과는 모든 반복에서 일치했다. 단위는 비용 초·예상 공차 거리 m다.

| 사례 | Greedy 비용 | Hungarian 비용 | 공차 거리 G/H | 배정 G/H | 비교 조건 |
|---|---:|---:|---:|---:|---|
| 동일 tick 3건 | 245 | 205 | 760 / 560 | 3 / 3 | 같은 요청 전부 배정 |
| 이동지원·마감 | 361 | 361 | 560 / 560 | 3 / 3 | V01만 이동지원 적합; 마감 요청은 예측 지각 |
| 장기 대기 화물 | 245 | 205 | 760 / 560 | 3 / 3 | 620초 기다린 화물의 공정성 기회 포함 |
| 요청 후 도로 폐쇄 | 168 | 168 | 560 / 560 | 2 / 2 | R2 경로 불가로 미배정 |
| 차량보다 많은 요청 | 245 | 126 | 760 / 250 | 3 / 3 | 서로 다른 요청 배정: 비용 개선으로 단정 불가 |

마지막 사례에서는 Greedy가 R4, Hungarian이 R1을 미배정으로 남긴다. 따라서 결과의 `same_served_requests=false`, `cost_reduction_s_same_requests=null`로 표시한다. 비용만 낮아진 것을 전체 서비스 개선으로 보고하지 않는다.

기본 사례 평균 Pickup ETA는 50.67→37.33초, 마지막 배정 요청의 완료 예측 시각은 simulation time 800→760초다. 배차 처리 p95는 기본 사례 Greedy 1.49ms/Hungarian 1.08ms였다. 측정 범위는 후보 경로 계산·우선순위/매칭·픽업 경로 설치이며, 시나리오 구성·deepcopy·증거용 경로 추출은 제외한다. 매 실행은 동일한 빈 경로 비용 cache에서 시작한다. 개발 PC의 작은 합성 지도 측정이며 전체 부하 성능 목표 통과를 의미하지 않는다.

## 검증과 한계

전체 Python/MapData 434개, Ruff, diff 검사 통과. 새 검사는 알려진 구간 비용, 경로 연결과 통행, 접근성·지각, 폐쇄 후 불가능 조합, 중복 배정 방지, 같은 요청 집합 비교 여부, 장기 대기 및 잘못된 입력을 확인한다. 실행 결과와 source hash는 `artifacts/validation/2026-09-26-route-dispatch/`에 있다.

이는 **합성 경로 기반 계획 비교**다. 실제 캠퍼스 graph/Stop, Physics 이동·완료/대기 시간, 실제 정시 도착률, 에너지·충전·허브, 희소 차량 패널티, 완료 요청 기준 서비스 공정성과 전체 E2/T23/M5 검증은 남아 있다. 실제 완료/대기 측정값은 null이며 예측 수치를 실측으로 바꾸어 표시하지 않는다. 기본 운영 배차 설정은 Greedy를 유지한다.
