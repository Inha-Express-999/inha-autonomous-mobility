## 현재 모델에서 확인한 문제와 구현 방향

- `CampusTowerFacadeLod`는 60주년과 하이테크에 동일한 청회색 유리·프레임 재질을 배정한다. 두 건물을 구분할 재질과 실루엣 대조가 필요하다.
- 현재 타워 생성은 원본 footprint의 높이와 공통 수평 분할에 의존한다. 사진의 저층부/고층부 구성을 확인한 뒤 분리해야 하며, 색상 변경만으로 사진 재현 완료를 주장하지 않는다.
- 건물 높이와 외곽을 바꾸면 일반·이동지원 출입구, 지형 지지 범위, collider 및 LOD bounds를 함께 재검사한다.
- 세부 창문 수보다 주요 매스, 밝고 어두운 면의 구성, 수직/수평 강조, 지붕 형태를 우선한다. 프로젝트용 Flat Kit 재질을 사용하고 공유 에셋 원본을 수정하지 않는다.
- 사진 검색에는 인천대학교와 성균관대학교 건물이 함께 노출됐다. 이 자료들은 인하대 모델 근거에서 제외한다. 검색의 자동 이미지 설명만으로 건물 신원·형태를 확정하지 않는다.

## 완료 증거

각 건물의 원본 사진 출처, 지도상 대응, 수정 전후 같은 시점 캡처, 유지된 출입구·접지 검사를 함께 남긴다. 현재 이 완료 증거는 미충족이다.

## 60주년기념관 재질 반영 — 2026-09-18
기사 원본 사진을 브라우저에서 직접 확인했다. 청록색 유리면, 짙은 회색의 굵은 테두리, 저층부와 고층부 구성이 보인다. 이를 기준으로 AnniversaryFacade 프로젝트 전용 재질4개를 생성하고 가까운/먼 LOD를 포함한 해당 건물 렌더러6개에 적용했다. 하이테크와 공유하던 원본 재질은 유지했다. 이번 변경은 유리·프레임 색조 분리이며, 곡선 테두리와 저층/고층 매스 재현은 아직 미완료다.


## 60주년 매스 대조
실제 씬 캡처 Iterations/anniversary-facade-review.png에서 전 외곽이 동일53.2m 높이로 압출된 문제를 확인했다. 사진의 저층동·타워 대비를 표현하기 위해 외곽을 두 부분으로 나눈 후보를 Iterations/AnniversaryMassing/proposal.json에 작성했다. 바닥 면적은 보존되며 저층19m와 분할위치는 사진 기반 합성 가정이다. 아직 모델에 적용되지 않았고 방향·비율의 시각 검수가 필요하다.


## 단순화 매스 적용 — 2026-09-18
기존 건물 하위 메시를 비활성 보존하고 Photo inspired massing을 생성했다. 저층19m/타워53.2m, 기존 바닥 외곽을 유지한331삼각형·3재질의 모델이며 MeshCollider와 Static Batching 설정을 적용했다. 이전 상세 타워 LODGroup은 비활성화했다. 출입구는 별도 루트이므로 위치를 유지한다. 곡선 테두리·타워 분할 방향은 여전히 사진 기반 단순화이며 후속 렌더 및 접지 검수가 필요하다.


## 매스 적용 검수
Iterations/AnniversaryMassing/applied-review.png에서 저층동·타워 높이 대비를 확인했다. 바닥246개 정점 접지 오차0m, collider와 렌더 메시 일치. 이후 사진의 굵은 회색 외곽을 강조하기 위해 모서리 수직 띠와 지붕 테두리를 추가했다(총359삼각형). 곡면 정밀 재현 대신 단순 평면 띠를 사용했다. 이 변경 이후의 최종 시각·접지 재검수와 다른 주요 건물 차별화는 남아 있다.


## 최종 테두리 적용 후 검수 — 2026-09-18
Unity MCP에서 활성 모델을 직접 검사했다. 359삼각형, 재질 3개, 바닥 정점 표본 288개에서 Terrain 접지 오차 0m이며 MeshCollider가 렌더 메시와 일치한다. 근거: `Iterations/AnniversaryMassing/final-validation.txt`.

`Iterations/AnniversaryMassing/final-review.png`는 최종 모델의 실제 렌더다. 저층부와 타워, 회색 수직 띠를 확인했다. 다만 사진에 비해 외곽 프레임의 곡면이 단순하고 유리면이 균일해 건물 외형 완료로 판정하지 않는다. 이 캡처에는 수목이 표시되지 않아 전체 조경 품질 검증에도 사용할 수 없다. 임시 검수 카메라는 촬영 후 제거했으며 기존 카메라 설정은 변경하지 않았다.

## 하이테크센터 사진 확인 및 매스 적용 — 2026-09-18
대한경제 기사(2022-09-21)의 사진 설명이 ‘인하대학교 하이테크센터 전경/인하대 제공’임을 확인하고 원본 이미지를 브라우저에서 직접 보았다. 밝은 석재·청록색 창과 낮은 날개동/높은 타워가 주요 특징이다.
기존 전체58m 유리 압출 형태를 보존 비활성화하고 동일 바닥 외곽을22m 날개동/58m 타워로 나눴다. 분할선과 높이/층수는 사진 기반 시각적 근사이며 실측값이 아니다. 원본 지붕 삼각분할로 오목한 외곽을 보존했다. 1,631삼각형, 프로젝트 전용 FlatKit3재질, MeshCollider/Static Batching 설정을 적용했다. 원본 타워 LOD는 비활성 보존한다.
근거: Iterations/HiTechMassing/proposal.json, validation.txt, applied-review.png. 타워 상부 캡·수직 유리띠·학교 표식과 실제 방향/치수 정합은 후속 보완 대상이다. 출입구는 별도 루트로 유지했다.

## 하이테크 입면 강조 후속 반영
사진에서 보이는 타워 끝면의 밝은 석재와 연속된 수직 유리띠, 어두운 상부 캡을 단순 평면으로 반영했다. 전체 반복창을 일부 줄여 메시가1,631→1,513삼각형으로 감소했다. 같은3재질·바닥 외곽·Collider를 유지하며 기존 발판/출입구를 이동하지 않았다. accent-review.png에서 적용 상태를 확인했다. 입면 분할 비율은 사진 기반 근사이며 학교 글자·곡면 등 세부 재현은 제외한 현재 모델이다.

## 정석학술정보관 중앙 입면 강조 — 2026-09-18
한국관광공사 제공 외관 사진(https://tong.visitkorea.or.kr/cms/resource/20/1577420_image2_1.jpg)을 브라우저에서 직접 확인했다. 중앙의 푸른 곡면 유리벽, 밝은 좌우 석재동, 위로 크게 돌출된 지붕을 확인했다. 기존 모델의 바닥 외곽과 건물 위치는 유지하고 중앙 유리벽을 12분할 곡면으로, 상부 지붕을 닫힌 단순 메시로 추가했다. 치수와 방향은 사진 및 현재 지도 외곽을 이용한 근사이며 실측 정합을 뜻하지 않는다.
CampusLibraryAccent.Apply()는 프로젝트용 재질 3개와 메시 1개(256삼각형)를 생성/갱신한다. FlatKit, MeshCollider 일치, Static Batching 적합 플래그를 적용했다. 실제 성능 측정은 별도다. 지상 4m 아래 형상은 추가하지 않았고 기존 출입구와 지형은 변경하지 않았다.
같은 카메라의 Iterations/jungseok-before.png와 jungseok-after.png에서 특징 추가를 확인했다. 첫 렌더 이후 지붕 상단 면 방향과 프레임 깊이 간격을 보완했다. 전체 층수·높이 비율과 현관 하부 캐노피는 사진과 차이가 남아 있으며 완전한 외형 재현으로 보고하지 않는다. 김현태인하드림센터는 아직 외관 검증·모델 보완이 남아 있다.

## 중앙 입면 렌더 갱신 보완
이전 단계의 격자 일부가 끊기는 표시를 수정했다. 유리/프레임을 같은 면 안의 비중첩 타일로 구성하고, CopySerialized 대신 Mesh API로 실제 버퍼를 갱신한다. 최신 모델은400삼각형/800정점이며 jungseok-fresh-buffer.png에서 격자의 연속성을 확인했다. 생성 반복 및 Terrain 재베이크 변화0m, Collider 일치를 jungseok-tiled-validation.txt에 기록했다. 층수/비율 등 기존 미완료 사항은 유지한다.

## 김현태인하드림센터 사진 대조 및 재질 분리 — 2026-09-18
[2017년 명명식 기사](https://www.veritas-a.com/news/articleView.html?idxno=77282)의 인하대 제공 사진을 브라우저에서 직접 확인했다. 회색 석재 명판 벽, 청록 창, 굵은 수평 캐노피와 기둥이 보인다. 사진은 전면 일부만 보여 전체 매스·정확한 방향·현재 외관을 확정할 수 없다. [인하대학신문 기사](https://www.inhapress.com/news/articleView.html?idxno=9996)로 인하드림센터1관과 김현태 명칭의 대응을 확인했다.
현재 해당 명칭의 씬 모델7렌더러에 프로젝트용 DreamCenterPalette4재질(석재/유리/금속/지붕)을 적용했다. FlatKit 기반이며 공유 원본은 변경하지 않았다. 바운드 중심 변화0m, 기존 geometry/Collider는 유지했다. dream-center-palette.txt 및 dream-center-palette.png에 근거를 남겼다.
이번 결과는 사진의 재질 색조 분리다. 해당 OSM 건물 외곽과 실제 전면 방향의 대응, 수평 캐노피·계단·일반/이동지원 현관을 포함한 외형 구현은 미완료다. 색상 조정만으로 건물 특색 재현 완료를 주장하지 않는다.
