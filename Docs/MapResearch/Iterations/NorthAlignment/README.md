# 북쪽 정합 보정 — 사용자 승인 후 적용

## 후속 부지 보정 적용 결과

### 접근로 생성 오류 수정

후속 검사에서 중간 단면 양끝을 높은 쪽 높이로 강제 통일하고 마지막 단면만 좌우 Terrain 높이에 맞추면서 마지막 0.25m에 단차가 집중되는 오류를 확인했다. `CampusEntranceApproaches`에서 좌우 높이 차를 유지하고 지형을 피하는 데 필요한 공통 상승량만 더하도록 수정했다. 제2생활관 이동지원 최대 종단 경사는 1.5478→0.0643, 5호관 이동지원은 0.7260→0.0941로 감소했다. 2호관 일반 접근로는 0.2116으로 여전히 가파르다. 수치는 합성 메시의 경사이며 접근성 기준 충족 판정이 아니다. 최신 결과는 `../entrance-approaches.txt`를 따른다. 지형 격자 한 개를 2m 높였을 때 접근 메시가 최대 1.733864m 반응하고 원래 높이·메시로 복원되는 검사도 통과했다.

2026-09-17 사용자가 “준비된 전체 보정안 적용 승인”으로 범위와 최대 7.59m 변화를 명시적으로 승인했다. 같은 `Refit North Aligned Building Pads` 메뉴를 실행하여 2,717개 높이 샘플을 변경하고 재베이크·씬 저장했다. `pre-pad-heights-f32.raw`에 직전 높이를 보존했고 `pad-refit.txt`에 결과를 기록했다. 아래의 승인 대기 설명은 이전 경과다.

재베이크 후 접근로의 샘플 매몰은 0m지만 최대 구간 경사가 제2생활관 이동지원 접근로에서 1.5478, 5호관 이동지원 접근로에서 0.7260으로 부적합하다. 인경호 수면 높이 1.901449m, 수면 꼭짓점의 최소 Terrain 여유 -1.4226m로 호숫가 일부가 물보다 높다. 평탄화 적용을 접근성·호숫가 검증 완료로 해석하지 않는다. 인접 패드 전이, 건물 높이 기준점, 수면/호안은 후속 보정 대상이다.

사용자가 “북쪽 정합 보정 적용 승인”으로 명시적으로 승인한 뒤 적용했다. 적용 후 지도 yaw는 약 0.000012°다. 아래 비교도와 초기 준비 기록은 적용 전 자료다. 최신 결과는 `applied.txt`와 작업 씬을 따른다.

후속 검사에서 일부 접근로와 지형 높이의 불일치가 확인되었다(제2생활관 접근로 최대 매몰 약 3.36m). 건물·운동장 부지 재형성 안은 별도 자동 승인 검토가 북쪽 정합 승인만으로 추가 평탄화 권한을 인정할 수 없다고 거절했다. 실제 지형에는 적용하지 않고 `pad-preview.txt`, `proposed-pad-heights-f32.raw`, `pad-review.png`로 계산만 했다. 7m 평탄 여유와 16m까지의 전이 구간에서 2,717개 격자가 바뀌며 최대 높이 변화는 약 7.59m다. 이는 실측 복원이 아닌 미술용 부지 정리안이다.

현재 `INHA UNIVERSITY` 루트의 yaw는 -27.600006°이고 Terrain은 축 정렬 상태다. OSM 정문/후문 노드와 제2생활관 외곽 중심을 대조하면 이 회전이 약 154m / 127m / 302m의 위치 차이를 만든다. 현재 Terrain이 제공하는 높이를 건물·도로에 베이크하는 것만으로는 이 지리적 불일치가 해소되지 않는다.

`source.json`에는 실제 Editor에서 읽은 높이 배열과 변환을, `scene-before.unity.txt`에는 저장된 씬 내용을 보존했다. 씬 스냅샷은 공유 메시를 참조하므로 독립 프로젝트 백업이 아니다. 원복 시 높이와 씬을 복원한 다음 파생 메시를 다시 베이크해야 한다.

`prepare_north_alignment.py`는 기존 조형과 원래 높이맵의 차이를 새 위치로 운반하고, 각 위치의 WGS84→AEQD 고도를 다시 샘플링한다. 8m 격자 사이 이중선형 보간으로 조형이 조금 부드러워질 수 있다. 출력 범위를 벗어난 높이는 0개이며 임의 클리핑하지 않았다. 기존 영역 밖으로 이동하는 Terrain 모서리에는 원본 근사 고도만 사용한다.

`review.png`는 원본 지도 데이터로 만든 전후 비교도이며 Unity 적용 결과가 아니다. 기존 평면 좌표의 축척은 유지하므로 AEQD와의 검사점 오차 0.04~0.69m는 남아 있다. 향후 Python↔Unity 좌표 계약 검증 완료를 의미하지 않는다.

적용 메뉴는 모든 시각 루트와 카메라를 +27.6° 회전하고 TerrainBinding의 원래 위치/높이 기준점을 함께 변환한 다음 준비된 높이를 베이크한다. Terrain 자체는 회전시키지 않는다. 승인 이후 출입구 접근 메시, 건물 부지, 호수 수심·수면, 도로 접합과 렌더를 다시 검증해야 한다.

2026-09-17 최초 자동 승인 거절 후 사용자에게 비교도와 변경 범위로 승인을 요청했고, 명시적 승인 후 같은 적용 메뉴를 실행했다. 추가 부지 보정의 거절은 별개이며 우회 실행하지 않았다.
