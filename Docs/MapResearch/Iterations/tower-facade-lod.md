# 고층 외관 단순화 · 2026-09-17

60주년기념관과 하이테크센터의 촘촘한 창틀·밝은 반사 패널이 원거리에서 흰 점처럼 보였다. 유리 반사색의 대비를 줄이고 화면 크기에 따라 외관 디테일만 교체하는 LOD를 추가했다.

| 건물 | 근거리 디테일 정점 | 원거리 디테일 정점 |
|---|---:|---:|
| 60주년기념관 | 282,420 | 332 |
| 하이테크센터 | 304,884 | 480 |

원거리 외관은 약 6m 간격 수직 분할선, 두 층 간격 수평선과 상·하부 테두리로 구성한다. 실제 창 개수나 층 구성을 측정한 복원 모델이 아니다. 기존 건물 본체, 지붕, 충돌 메시와 출입구는 교체하지 않았다. 근거리 원본 메시도 유지한다.

LOD 전환은 화면 비율 0.55와 0.012이며 LOD 크기는 건물 높이 53.2m/58m를 사용한다. 긴 건물 외곽 폭 때문에 작은 창틀이 원거리까지 유지되는 것을 피한다. 건물 높이는 기존 합성 모델 값이다. 창틀의 개별 그림자는 껐고 본체 그림자는 유지했다. 건물용 원본 공유 재질은 수정하지 않고 별도 Flat Kit 재질을 생성했다.

검증 자료는 `tower-lod-near.png`/`tower-lod-far.png`의 같은 카메라 강제 LOD 비교와 `anniversary-auto-near.png`, `anniversary-auto-far.png`, `hitech-auto-near.png`, `hitech-auto-far.png`의 자동 거리별 캡처다. 검사 후 ForceLOD(-1)로 자동 선택을 복원했다. 수정된 `lake.png`에서도 원거리 창틀 무늬 감소를 확인했다. 정점 수 감소를 FPS 개선 실측으로 해석하지 않는다.

외관 참고 사진 후보는 [60주년기념관 기사](https://news.unn.net/news/articleView.html?idxno=523193), [하이테크센터 기사](https://www.dnews.co.kr/uhtml/view.jsp?idxno=202209211119048250511)다. 이 작업은 색감과 표현 단순화이며 건물별 사진 기반 저층부/고층부 형태 검증 완료가 아니다.

부지 평탄화는 앞선 자동 승인 검토 거절 이후 아직 미적용이다. 이 작업에서 지형을 변경하지 않았다.
