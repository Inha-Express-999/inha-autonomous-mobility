# 캠퍼스 조경 초안

2026-09-17, CampusTerrain 작업 씬의 `Campus planted groves`에 Idyllic Fantasy Nature 활엽수 3종 43그루를 배치했다. 실제 수목 위치가 아닌 미술용 배치다. 녹지 원본 메시 내부의 후보를 사용하고 가장자리 8방향 6m 검사, 중심 간격 15m, 건물·수면 렌더링 경계 여유를 적용했다. 도로 그래프와 수관 전체의 교차 검증은 후속 작업이다.

높이는 약 6~8m로 맞추고 프리팹/LOD 구조를 유지했다. 각 나무는 Vegetation Terrain 바인딩을 가지며 높이 재베이크 대상이다. 설치 에셋의 잎이 초기 렌더에서 보이지 않아 모델과 잎 텍스처는 유지한 채 프로젝트 소유 Flat Kit 잎/나무껍질 재질로 바꿨다. 원본 패키지 재질은 변경하지 않았다. 근접 렌더에서 잎 표시를 확인했다.

`groves.txt`는 생성 결과, `lake.png`는 인경호 주변, `terrain-overview.png`는 전체 화면이다. PC/모바일 성능과 최종 출입구·차량 동선 배치 이후의 수목 간섭 검사는 미완료다.
