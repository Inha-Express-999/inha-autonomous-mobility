# 도로 주변 지형 정리

사용자 요청: 도로의 과도한 높이 요철을 줄이고 가능한 구간을 평탄화.

- `before.raw`: 적용 전 257×257 float32 정규화 높이. 원점/크기는 `grid.json`.
- `roads-xz.raw`: 활성 아스팔트 81개 메시의 XZ 삼각형. 보행로는 차량 도로로 합치지 않았다.
- `protected-bounds.raw`: 건물·수변 구조·운동장 보호 범위. 보호 범위의 입력 높이는 변경하지 않는다.
- `AgentScripts/grade_road_terrain.py`: 20m 규모의 높이 평활화, 도로 주변 8m 적용 및 32m까지 점진 혼합. 실제 도로 설계고가 아닌 시각화용 합성 보정이다.
- `graded.raw`: 적용 데이터. 원본 높이 백업은 덮어쓰지 않는다.
- `report.json`: 보호 경계에서 떨어진 도로 격자 3,010개에서 요철 RMS 0.666→0.246m. 이 지표는 전체 도로의 통행성이나 차량 경사 검증이 아니다.
- `verified.txt`: 적용 후 도로 81개, 메시 표본 7,888개와 Collider를 확인. 메시-지형 높이 차이 최대 약 0.000092m. Unity 높이 저장 양자화에 의한 입력 배열 차이는 정규화 0.00001526, 약 1.53mm.

도로·차선·연석·녹지·부착 객체를 Terrain Bake로 다시 맞추고 씬을 저장했다. 건물 보호 범위와 겹치는 도로, 교차로 및 진출입부 경사는 후속 점검 대상이다. 원본 복구 시 before.raw를 같은 지형에 넣고 다시 Bake해야 파생 메시도 함께 복구된다.
