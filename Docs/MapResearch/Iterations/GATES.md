# 정문·후문 초안

2026-09-17, CampusTerrain 씬의 `Campus gate drafts`에 정문/후문을 추가했다. OSM node 4741793208과 4741793209의 경위도를 기존 legacy 지도 투영 및 씬 회전에 맞춰 배치했다. 실제 게이트 외형·방향·통과 위치는 확인되지 않았으며 현재 구조물은 미술용 제안이다.

각 게이트에 일반/장애인전용 통과 앵커를 따로 만들었다. 최초 배치에서 차도 간섭을 발견해 `gate_passage_drafts.json`의 도로 바깥 후보로 이동했다. 기존 road 중심선과 저장 폭 기준으로 앵커 중심에서 도로 가장자리까지 약 4.6~5.1m이며 실제 도로 폭/현장 통행 조건을 검증한 수치는 아니다. 인접 건물 내부 후보를 제외했고, 최종 렌더에서 차도 위 구조물을 이동한 결과를 확인했다. 보도 접속 및 전체 구조물 여유 검사, 경사·접근성 검증은 남아 있다.

두 게이트는 별도 CampusLandmarkEntrances를 가지고 routeValidated=false다. 최초 표지 기단은 차도 간섭을 줄이기 위해 비활성화했다. `entrances-main_gate.png`, `entrances-rear_gate.png`가 최종 비교 화면이다.

현재 씬 기준 합계는 건물 4곳+게이트 2곳, 총 6개 랜드마크·12개 분리 출입 앵커다. 인하대역·비룡플라자·제1/2/3생활관은 여전히 미완료다. 씬 외형 초안을 서비스 가능한 Stop으로 취급하지 않는다.
