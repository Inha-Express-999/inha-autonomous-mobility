# 운동장 서쪽 자율주행 허브 — 작업 씬 초안

2026-09-17 사용자 확정 위치: 북쪽이 위인 지도에서 대운동장 서쪽 주차장.

`Assets/CampusSim/Scenes/CampusTerrain.unity`의 `West Field | Autonomous Mobility Hub`에 생성했다. 원본 InhaCampus 씬은 이 작업으로 교체하지 않는다. OSM 주차장 way/568420971 내부의 기존 지도 좌표 (-300, 15)를 중심으로 배치하며, 사용자가 적용한 지도 회전을 따라간다.

흰색 캐노피, 태양광 패널 외형, 청록색 유도선, 충전기 3개, 운영동, 보행 대기공간, 진입/출차 경사판으로 구성한다. 재질은 설치된 Flat Kit를 사용한다. 상세 치수와 시설 배치는 실제 시설이 아닌 시뮬레이션용 제안이다.

초기 3대의 출발 앵커 `Spawn_Bay_01..03`, 진입/출구, 출차 대기선, 일반/이동지원 대기 위치를 `CampusVehicleHub`에 연결했다. 미출차 차량은 향후 이 베이에서 생성하도록 Python 서버와 연결해야 한다. 현재 충전·점유·배차·주행 로직은 없으며 진출입 도로 연결과 보행 접근성은 미검증이다. 앵커 JSON을 검증된 운행 지도 데이터로 사용하지 않는다.

Terrain 편집 후 `Campus > Map > Bake Terrain Bindings`를 실행하면 허브와 자식 앵커가 함께 높이를 갱신한다. 전체 높이 +1m → 재베이크 → 원래 높이 복원 검사를 통과했다. 이 검사는 중심 높이 추종만 확인하며, 임의 경사에서 부지 평탄화/출입 경사판 접합이나 차량 통행성을 보장하지 않는다. 근사 DSM과 기존 지도 좌표계의 통합도 전체 지도 후속 작업이다.

검증 결과: `west-field-hub-validation.json`. 실제 Editor 렌더: `west-field-hub.png`. Unity 메뉴로 생성·저장·검증했고, 생성 후 콘솔 오류/경고는 0건이었다. PC/모바일 빌드 성능은 아직 측정하지 않았다.

전체 캠퍼스의 건물 사진 반영, 11개 랜드마크별 출입구, 수목·수면, 지형/도로 접합 개선은 별도 진행 중이다. 본 기록은 전체 목표 완료 보고서가 아니다.
