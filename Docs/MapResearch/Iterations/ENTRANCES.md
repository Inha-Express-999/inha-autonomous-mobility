# 분리 출입구 초안 — 미완료

2026-09-17: 5호관, 2호관(현재 2북관 형상), 하이테크, 60주년기념관에 일반/장애인전용 출입구를 각각 만들어 총 8개를 배치했다. `CampusLandmarkEntrances`는 두 앵커와 exclusive 플래그를 보존하며, `routeValidated=false`다. 실제 출입구나 접근성을 검증한 데이터가 아니며 운행 Stop으로 사용하지 않는다.

`AgentScripts/prepare_entrance_drafts.py`가 기존 footprint 긴 외벽의 30%/70% 위치에 합성 후보를 만든다. 이는 실제 출입구 추정 알고리즘이 아니라 시각 초안 생성 규칙이다. `Assets/CampusSim/Data/entrance_drafts.json`에 좌표와 미완료 시설 7개를 기록했다. 제3생활관 등 미확인 건물은 임의로 생성하지 않았다.

각 출입구 그룹은 해당 건물의 Terrain 높이 앵커를 공유한다. 간격 검사 결과 23.37~54.51m이며 모두 별도 Transform이다. 검사는 `entrance-validation.txt`, 네 건물의 렌더는 `entrances-*.png`다.

시각 확인에서 60주년기념관 후보의 지형 가림을 발견해 반대 외벽으로 재배치하고 국소 부지 높이를 조정했다. 두 출입구는 약 26.9m 떨어져 있으며, 각각의 근접 렌더 `anniversary_60_general.png`와 `anniversary_60_accessible.png`에서 표시를 확인했다. 기존 유리 외벽과의 겹침도 표현 깊이 조정으로 보정했다. 넓은 카메라 구도는 이웃 건물 내부에 들어가므로 해당 건물은 개별 근접 렌더를 기준으로 확인한다. 나머지 세 건물도 두 포털의 표시를 확인했으나 보도 연결·단차·도로 간섭은 미검증이다. 합성 부지 정리는 측량 경사나 장애인 접근성 검증을 대체하지 않는다.

남은 필수 랜드마크: 정문, 인하대역, 후문, 비룡플라자, 제1·2·3생활관. 전체 11개 랜드마크 및 각각의 두 출입구 요구는 아직 완료되지 않았다.
