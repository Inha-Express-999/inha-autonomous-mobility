# Terrain 지면 접합 보정

2026-09-17 작업 씬 `CampusTerrain.unity`에 적용했다. 전체 캠퍼스 완성 보고서가 아니다.

기존 10m 삼각형이 굴곡을 직선으로 건너뛰어, 진단한 도로 메시 변의 중간점에서 Terrain 높이와 최대 약 1.45m 차이가 났다. 먼저 다중 재질 메시 누락을 확인했으나 해당 대상은 0개였고, 실제 원인은 지형을 표현하기에 성긴 삼각형이었다.

최종 구현은 원본 메시를 `CampusTerrainBinding.originalMesh`로 보존하고 매 베이크마다 적응형 세분화를 수행한다. 지형을 샘플링한 변 중간점과 삼각형 중심의 선형 보간 오차가 0.025m를 넘으면 세분화한다. 평면 방향 변 길이는 최대 24m, 재귀 깊이 제한은 24다. UV와 재질별 삼각형 인덱스를 유지한다. 이는 샘플 지점의 표현 오차 검사이며 모든 지점의 수학적 오차 상한이나 실제 측량 정확도가 아니다.

검사 결과는 `surface-geometry.txt`에 있다. 아스팔트/보도/연석/차선의 검사된 변 중간점 최대 오차는 각각 약 0.025m 이하이다. 2m 일괄 세분화 중간안의 생성 메시 파일 합계 561,932,373바이트를 최종 82,704,783바이트로 줄였다. 이 수치는 source/baked 자산 파일 합계이며 모바일 메모리/FPS 측정값이 아니다.

Unity MCP로 작업 씬 저장 및 동일 카메라 재렌더를 완료했다. 콘솔 오류는 확인되지 않았고 Unity AI Toolkit Account API 연결 시간초과 경고 1건이 있었다.

남은 사항: 기존 지도 회전/근사 투영과 고도 데이터의 좌표 통합, 인위적으로 급한 부지 경사 완화, 건축 세부 구조의 강체 바인딩 정리, 평평한 수면 처리, 출입구/도로의 실제 접근성 확인, 국소 Terrain 변경/재로드 검사, PC·모바일 성능 검사. 단순 높이 추종을 운행 가능 판정으로 사용하지 않는다.
